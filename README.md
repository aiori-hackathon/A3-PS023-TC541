## 📌 About the Project
This repository contains the initial work for our AIORI Hackathon 3 problem statement, PS-023, focused on a minimal two-node Cloud Hypervisor VM controller.

Our proposed objective is to explore centralized virtual machine management across two Linux hosts using Cloud Hypervisor and KVM.

## 🛠️ Project Status
**Current stage:** Initial setup and planning.

Implementation and testing are ongoing.
